# geometric-brownian-motion

## Overview
GBM implementation with Monte Carlo option pricing and 
live calibration from Yahoo Finance data.

## Theory
dS = µS dt + σS dW_t

## Features
- [ ] Exact GBM path simulation
- [ ] Black-Scholes closed-form pricing
- [ ] Monte Carlo with confidence intervals
- [ ] Greeks (Delta, Gamma, Vega, Theta)
- [ ] Historical volatility calibration
- [ ] Jupyter notebooks with visualisations
